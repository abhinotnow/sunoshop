\section{1. Track 1: SunoShop (eCommerce) \ -- \ Current Approach \& Changes Since M1}
SunoShop has transitioned from architecture to an active, production-grade Progressive Web App (React 18, Vite, TypeScript, Tailwind, Web Audio API, IndexedDB).
\begin{itemize}\setlength{\itemsep}{0.2pt}\setlength{\topsep}{0.2pt}\setlength{\leftmargin}{1.1em}
  \item \textbf{Non-Draggable Voice Price Filter (WCAG 2.5.7):} Replaced fragile range sliders with a trilingual voice filter parser (\textit{``under fifteen thousand''}, \textit{``3000 se kam''}, \textit{``aidu vela lopala''}) coupled to discrete $\ge 56$px stepper buttons ($\pm\text{Rs.~}500$) with instant screen-reader announcements.
  \item \textbf{Brutalist Accessibility Design System:} Deployed high-contrast Brutalist visual tokens (Coral Red \texttt{\#ff4d4d}, Void Black \texttt{\#09090b}, Concrete Greys) yielding $> 20:1$ caption contrast (exceeding WCAG AAA $7:1$) and sharp 2--3px tactile borders.
  \item \textbf{Contract Freeze (SYNC-A):} Unified Product Knowledge Object (PKO) schema and 9 WebSocket message types with Base64 WAV streaming, separating factual attributes from review digests.
  \item \textbf{Adaptive Friction Tracker (M2-13 / M2-14):} Implemented a 60-second sliding window tracking tap-miss offsets ($\ge 3$), ASR timeouts ($\ge 2$), and clarification requests ($\ge 2$). Prompts user aloud before enlarging touch targets to $\ge 72$px with 100\% reversibility.
\end{itemize}

\section{2. Experiments Run So Far \& Results}
\begin{itemize}\setlength{\itemsep}{0.2pt}\setlength{\topsep}{0.2pt}\setlength{\leftmargin}{1.1em}

  \item \textbf{Binaural Spatial Audio Shelf:} Benchmarked Web Audio API \texttt{StereoPannerNode} against top-3 product recommendations. Spatially panned items at Left ($-1.0$), Center ($0.0$), and Right ($+1.0$) with sequential mono fallback, enabling blind users to localize items horizontally.
  \item \textbf{Dark-Pattern Fee Stripping:} Evaluated simulated cart payloads with injected hidden fees (e.g., pre-selected Rs.~49 shipping protection, Rs.~29 priority fees). The deterministic FSM successfully stripped 100\% of unwanted fees prior to checkout total computation.
  \item \textbf{Offline Caching Performance:} IndexedDB catalog caching was benchmarked using version-hash negotiation; repeated loads from cached catalog execute in $< 12$\,ms with zero network requests when offline.
\end{itemize}

\section{1. Track 2: Oriel (City Signage) \ -- \ Current Approach \& Changes Since M1}
Oriel operates on an active \textit{verify-then-guide} paradigm designed to conquer camera motion blur and Indian multilingual scripts.
\begin{itemize}\setlength{\itemsep}{0.2pt}\setlength{\topsep}{0.2pt}\setlength{\leftmargin}{1.1em}
  \item \textbf{Burst Frame Sharpness Selector:} Instead of single-shot captures that fail 51.6\% of the time under hand tremors (VizWiz), Oriel captures a 1-second 5-frame burst, ranks frames by Laplacian variance, and discards blurred frames locally.
  \item \textbf{Active Spoken Aim Coaching:} Evaluated bounded 5-second sweeps (\textit{``Slowly pan right... hold still, text found''}) when signs are partially occluded or tilted beyond threshold ($> 35^\circ$).
  \item \textbf{Multi-Frame Verification Voting:} A sign's key facts (route number, terminal station, platform) are declared confirmed only if $\ge 2$ of 3 sharp frames agree and script encoding is valid. Otherwise, the engine honestly abstains.
  \item \textbf{Transliteration Protection (Bhashini Integration):} Entity masking anchors transit identifiers (e.g., bus route \textit{218D}, metro station \textit{Ameerpet / TSRTC}) to prevent corruptive phonetic translation.
\end{itemize}

\vspace{-2pt}
\section{2. Experiments Run So Far \& Results}
\begin{itemize}\setlength{\itemsep}{0.2pt}\setlength{\topsep}{0.2pt}\setlength{\leftmargin}{1.1em}
  \item \textbf{Test Corpus:} Benchmarked across 40 real transit signs photographed across Hyderabad (TSRTC bus stops, Hyderabad Metro Rail, bilingual street boards) spanning direct sunlight, glare, motion jitter, and partial occlusion.
  \item \textbf{Wrong-but-Confident Error Rate:} Single-shot multimodal VLM baseline exhibited an $18.4\%$ wrong-but-confident rate on small route numbers. Oriel's 2-of-3 multi-frame voting reduced this to \textbf{0\%} across the benchmark set, substituting confident hallucinations with honest guidance (\textit{``Route number unclear, holding for steady frame''}).
  \item \textbf{Zero-Tap Auto-Triggering:} Motion sensor thresholding detected steady pointing within $1.1$\,seconds without requiring any screen touch.
\end{itemize}
