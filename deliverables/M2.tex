\begin{itemize}\setlength{\itemsep}{0.2pt}\setlength{\topsep}{0.2pt}\setlength{\leftmargin}{1.1em}

  \item \textbf{Entity Masking \& Grounded RAG (M1-12 -- M1-16):} Bidirectional translation masks numbers, prices, and brand entities into placeholders (\texttt{\_\_PRICE\_0\_\_}), guaranteeing 100\% entity survival. Strict grounding rejects any unverified model claims.
  \item \textbf{Guardian Checkout \& Dark-Pattern Stripper (M1-21 -- M2-17):} Deterministic non-LLM state machine purges unconsented add-on fees with strikethrough badges, assertive live-region alerts, and tactile error haptics; verbal confirmation phrase (\textit{``Confirm Blue Falcon''}) prevents unauthorized checkout.
  \item \textbf{Adaptive Friction Tracker \& Explain Simpler (M2-13 -- M2-15):} Sliding window tracks touch offsets ($\ge 3$), ASR timeouts ($\ge 2$), and clarification requests ($\ge 2$); prompts user aloud before enlarging touch targets to $\ge 72$px; ``Explain Simpler'' control modulates speech rate to $0.8\times$ with $+300$\,ms inter-sentence pauses.
\end{itemize}

\section{1. Track 2: Oriel (City Signage) \ -- \ Current Approach \& Changes Since M1}
Oriel operates on an active \textit{verify-then-guide} paradigm designed to conquer camera motion blur and Indian multilingual scripts.
\begin{itemize}\setlength{\itemsep}{0.2pt}\setlength{\topsep}{0.2pt}\setlength{\leftmargin}{1.1em}
  \item \textbf{Verify, Then Guide Philosophy:} Handles bus boards, bus stops, metro/platform signs, direction boards, street names, signals, and shop boards. Core rule: never sounds sure when not. Verified facts are spoken as \textit{``The sign says...''}; uncertain facts as \textit{``It looks like..., please check''} or actionable repositioning prompts.
  \item \textbf{Vision Pipeline (Photo to Speech):} (1) \textit{Capture:} Evaluates sharpness, brightness, glare, and tilt 4$\times$/s; grabs a 6-frame burst over 1\,s, keeping the 3 sharpest; blurs faces on-device via MediaPipe. (2) \textit{Reader 1:} Gemini 3.5 Flash-Lite parses 3 frames in parallel for route, place, and signal status. (3) \textit{Reader 2 + OCR:} Independent Flash-Lite pass on zoomed crop plus Bhashini OCR on tight crops. (4) \textit{Verify:} Fixed rule engine; bus numbers require 2 clear frames plus agreement from Reader 2 or OCR. (5) \textit{Guide:} Diagnoses aiming faults (too far, cut off, glare, dark, tilt) with spoken advice up to 3 retries before bystander fallback (\textit{``Please ask someone nearby''}). (6) \textit{Compose:} Key facts inserted into fixed reviewed Indic templates with digit-by-digit bus numbers voiced by Bhashini TTS.
  \item \textbf{Bhashini Speech-to-Speech Q\&A:} 16\,kHz audio $\to$ Bhashini ASR $\to$ translate to English $\to$ Gemini answers grounded strictly in verified sign facts $\to$ Bhashini translation back $\to$ Bhashini TTS. Misheard questions return yes/no confirmations instead of guesses.
  \item \textbf{Stack \& Head Gestures:} React 19, Three.js 3D status orb, MediaPipe Tasks (face blur and 478-landmark head gestures: nod for yes, shake for no, tilt for again); FastAPI on Python 3.12 (audioop workaround); Cloudflare HTTPS tunnel; 56px touch targets, text scaling to 1.8$\times$.
  \item \textbf{Changes Since M1:} Single read $\to$ 3-frame burst with 2 independent readers; fixed reviewed templates replace raw MT; custom async AnuvaadHub client replaced official SDK; moved from Gemini 3.8 Flash to 3.5 Flash-Lite ($>25$\,s timeouts); eliminated Supabase for zero-data retention.
\end{itemize}

\vspace{-2pt}
\section{2. Experiments Run So Far \& Results}
\begin{itemize}\setlength{\itemsep}{0.2pt}\setlength{\topsep}{0.2pt}\setlength{\leftmargin}{1.1em}
  \item \textbf{Live Bhashini Integration (14 of 15 Models Verified):} Translation (6 pairs, 0.16--2.35\,s), TTS (1.5--2.2\,s), and ASR (0.6--5.8\,s) all functional. Speech generated by Bhashini and fed back into ASR returned exact strings across all three languages (\textit{``Bus stop''}, Hindi \textit{``Bus stop''}, Telugu \textit{``Bus stop''}). Telugu OCR returned HTTP 500 from AnuvaadHub, so it is safely bypassed via dual readers backed by 94 Hyderabad places and 57 metro stations.
  \item \textbf{Model Latency \& Selection:} Gemini 3.8 Flash timed out twice ($>25$\,s), whereas Gemini 3.5 Flash-Lite answered in 5.7\,s; adopted Flash-Lite for both independent readers to ensure sub-6-second pedestrian responsiveness.
  \item \textbf{OCR Preprocessing Optimization:} Whole-sign OCR corrupted SECUNDERABAD into \textit{``seCUNnDErARAO''}. Iterated to tight route-number cropping, Otsu thresholding, center-contrast polarity check, white border padding, and fuzzy matching, eliminating recognition garble.
  \item \textbf{iPhone Safari Hardening:} Removed React StrictMode (prevented double camera initialization), engineered custom WAV encoder (circumventing Safari AAC limitation), and consolidated audio/camera/motion permissions into a single initial tap.
\end{itemize}
